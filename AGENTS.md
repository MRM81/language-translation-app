# Agent Behaviour Rules

**Project:** My Translation App

---

## Source of Truth

This folder is the source of truth.

The chat history is not the source of truth.

---

## Before Writing Any Code

Builder agents must read these files before starting any work:

1. project-start.md
2. planning/STATE.md
3. planning/INTAKE.md
4. planning/DOMAIN.md
5. Any relevant sprint files in planning/sprints/

---

## Rules

- Do not invent business rules.
- Do not make assumptions about user intent.
- Stop and ask when unclear.
- Work sprint-by-sprint. Do not jump ahead.
- Run a dry-run before applying any Architect Pack.
- Summarise what will change and wait for approval.
- Update planning/STATE.md after completing work.
- Update planning/FILE_INVENTORY.md when new files are added.

---

## Architect Pack Workflow

1. The Architect Pack is generated by the Architect layer (ChatGPT / Claude).
2. The Builder reads the pack and confirms understanding.
3. The Builder runs a dry-run.
4. The Builder summarises the changes.
5. The Builder waits for explicit approval.
6. The Builder applies the pack.
7. The Builder updates planning files.

---

## When Blocked

Stop. Do not guess. Ask the user to clarify before continuing.
