# Sprint 018 — Requirements

**Sprint:** 018 — UI/UX Redesign
**Status:** Completed
**Completed:** 2026-05-31

---

## Goal

Redesign the user experience so the app feels like a polished portfolio-ready product rather than a feature-heavy prototype.

---

## Requirements

1. Add landing page as the default first screen.
2. Landing page must include: logo, product name, short description, "Start Translating" CTA, feature highlights.
3. Add logo from `design/inspiration/logo.png`.
4. Add favicon from `design/inspiration/favicon.png`.
5. Translation Mode must show Text or Audio form, not both at once.
6. Use a Text Translation / Audio Translation segmented toggle.
7. Conversation Mode must remain accessible from the translator workspace.
8. No new backend features.
9. No authentication or databases.
10. No major design library introduced.

---

## Preserved Features

- Text Translation
- Audio Translation
- Conversation Mode
- Push-To-Talk
- Multi-conversation management
- Conversation search
- Persistence
- Export features (TXT / JSON / Clipboard)
