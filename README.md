## Architect / Builder Workflow

This project follows the AI Architect / Builder methodology.

| Layer | Role | Tool |
|-------|------|------|
| Architect | Discovery, design, planning | ChatGPT / Claude |
| Builder | Implementation, execution | Claude Code / Codex |

**The project folder is the source of truth — not the chat.**

### Workflow Steps

1. Start Architect chat using `architect-chat-starter-prompt.md`.
2. Run discovery. Do not skip this.
3. Generate Architect Pack 001 **only after explicit approval**.
4. Save Architect Pack into the project folder.
5. Builder reads the Architect Pack before any code.
6. Builder runs a dry-run and reports what will change.
7. Apply only after review.
8. Update planning files after each sprint.
